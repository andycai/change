# 5. Workflow & Preferences (工作流与个性化偏好)

*个人研发习惯和工具偏好*

- **简单文件编辑：** 用 Python 脚本改了少量源码/测试文本 -> 简单手工编辑必须优先使用 `apply_patch`
- **编写代码前：** 直接执行编写代码 -> 需要询问是否创建新的 worktree 并在新的 worktree 中执行 
- **代码提交风格：** 提交时没使用前缀 -> 始终使用 `feat:`、`fix:`、`chore:`、`docs:`、`refactor:` 等前缀
