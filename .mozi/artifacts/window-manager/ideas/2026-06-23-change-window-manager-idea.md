# 窗口管理封装

## 技术栈

- 使用基于 YooAsset 封装的高层抽象的接口，在 Assets/Change/Runtime/Asset 下
- 使用 FairyGUI 来做 UI，但是是否使用 FairyGUI 原生的 Window 概念来做窗口管理需要讨论，自定义是否更灵活可控？
- 使用 UniTask 来做异步加载

## 窗口UI

使用 FairyGUI 的 Window 还是自定义需要讨论

## FairyGUI 包加载

使用 UniTask 来异步加载 FairyGUI 的包和图集。

## 窗口生命周期

窗口被关闭后，不是马上就释放掉，窗口需要有自己的生命周期，生命周期过了才会销毁（还要考虑下面说的缓存，如果再缓存中也不会被释放）

## 窗口层级管理

窗口需要有不同的层级属性，高层级的窗口在低层级的上面显示，不管是先打开还是后打开。

## 窗口分组

同一组的窗口是层叠打开的，不会被最新打开的窗口关闭，如果有不同组的窗口要打开，那么不同组的其他所有窗口都要关闭。还要考虑一种情况，有临时特殊打开的窗口，虽然不是同一组，但是他是在其他组中需要独立打开查看，需要有一个特殊的组来处理这种情况。

## 窗口缓存

使用 LRU（最近最少使用）来缓存最近 10 个窗口（可配置）
