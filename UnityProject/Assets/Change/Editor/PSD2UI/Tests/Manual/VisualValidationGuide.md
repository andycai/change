# PSD 文字效果视觉验证指南

## 目的

验证 PSD 文字效果在 Unity 中的还原度是否达到 90% 以上。通过对比 Photoshop 原始导出与 Unity 渲染截图的逐效果差异，确保视觉质量满足项目标准。

---

## 测试 PSD 准备说明

测试 PSD 文件 (`test-effects.psd`) 应包含以下 **7 个文本图层**，每个图层仅应用指定的一种或多种效果：

| 图层 | 应用效果 | 参数 |
|------|---------|------|
| 文本1 | 描边 (Stroke) | 2px 黑色外描边 |
| 文本2 | 阴影 (Drop Shadow) | 偏移 (2, -2)，模糊半径 4 |
| 文本3 | 内阴影 (Inner Shadow) | 偏移 (2, -2) |
| 文本4 | 渐变 (Gradient Overlay) | 垂直方向，黄色 (#FFFF00) → 橙色 (#FF8800) |
| 文本5 | 发光 (Outer Glow) | 黄色，大小 5 |
| 文本6 | 斜角 (Bevel & Emboss) | 外斜角，大小 5 |
| 文本7 | 组合效果 | 描边 + 阴影 + 发光 |

### 生成 JSON

在 `PSDExporterProject` 中运行以下命令，将测试 PSD 转换为中间 JSON 格式：

```bash
cd PSDExporterProject
npm run build
node dist/cli.js parse test-effects.psd --output test-effects.json
```

生成的文件：
- `test-effects.json` — 中间 JSON，包含每个文本图层的效果参数
- Unity Prefab `TestEffects.prefab` — 由 Generator 根据 JSON 生成的 Unity 预制体

## 验证步骤

### 1. 准备对比截图

- **Photoshop 侧**：将每个文本图层单独导出为 PNG（300 DPI），作为参考标准。
- **Unity 侧**：在 Game 视图中截取每个文本对象的渲染画面，确保分辨率与 PS 导出一致。

### 2. 逐效果验证

逐一对比 PS 参考图与 Unity 截图，按照以下清单评估每种效果。

#### 描边 (Stroke)

- [ ] 颜色匹配：目标 100%
- [ ] 宽度匹配：允许 ±0.5px 误差
- [ ] 位置（外/内/居中）：目标 100%

#### 阴影 (Drop Shadow)

- [ ] 颜色和透明度：允许 ±5% 误差
- [ ] 偏移量：允许 ±1px 误差
- [ ] 模糊半径：允许 ±20% 误差（Shader 实现差异）

#### 内阴影 (Inner Shadow)

- [ ] 整体视觉效果类似（重点评估）
- [ ] 颜色匹配：允许 ±10% 误差
- [ ] 如果效果差异大于 30%，标注为已知限制

#### 渐变 (Gradient Overlay)

- [ ] 颜色 1 和颜色 2：允许 ±5% 误差
- [ ] 渐变方向（垂直/水平）：目标 100%
- [ ] 颜色过渡平滑度：主观评估

#### 发光 (Outer Glow)

- [ ] 颜色匹配：允许 ±10% 误差
- [ ] 扩散范围：允许 ±15% 误差
- [ ] 整体发光效果可见

#### 斜角 (Bevel & Emboss)

- [ ] 高光和阴影可见：目标 100%
- [ ] 深度感：主观评估
- [ ] 允许参数映射差异，重点关注整体视觉效果

#### 组合效果 (Combined Effects)

- [ ] 各组件效果（描边/阴影/发光）叠加后互不覆盖、互不干扰
- [ ] 整体视觉效果与 PS 参考一致：允许 ±10% 误差
- [ ] 三种效果的相对层次顺序正确（描边在最外层，阴影在最下层，发光在外围）

## 评分标准

| 等级 | 还原度 | 说明 |
|------|--------|------|
| **A 级** | ≥ 95% | 几乎完全一致，细微差异不影响整体视觉效果 |
| **B 级** | 90% – 94% | 整体效果一致，存在可接受的参数级差异 |
| **C 级** | 85% – 89% | 效果可识别，但有明显差异需要关注 |
| **D 级** | < 85% | 效果差异过大，必须优化 |

**目标：所有效果达到 B 级以上（≥ 90% 还原度）。**

## 已知限制

以下为当前实现中与 Photoshop 的已知差异，评估时请参考：

- **内阴影**：使用 `_UnderlayDilate` 负值实现，视觉效果可能与 Photoshop 原生渲染存在差异。如果差异显著（> 30%），应标注为已知限制而非实现缺陷。
- **斜角效果**：光照模型与 Photoshop 不完全相同，深度感和光泽表现可能略有不同。评估时应重点关注高光/阴影的相对关系是否正确。
- **渐变方向**：当前仅支持垂直（0°）和水平（90°）方向。斜向渐变和径向渐变已降级为垂直方向，测试时请使用垂直或水平渐变。
- **模糊精度**：Unity Shader 的模糊算法与 Photoshop 的 Gaussian Blur 在实现上有差异，边缘柔和程度可能不完全一致。
